Release notes

What changed in each version of SNESForge. The newest is at the top.

Version 2.0.1 26 November 2026Latest

  • Check for updates. In Settings, under More. It asks GitHub for the newest version only when you tap it.
  • More apps. Other free apps by the same developer, each opening its website, and a link to this website.
  • The bottom bar now shows the selected page with a highlight behind its icon.
  • Fixed: Tile size always showed Medium as chosen, whatever size was in use.
  • Fixed: in Controller Studio, the Small, Medium and Large buttons did not move the Overall size slider, and choosing a button on the preview left the Selected control size slider showing the previous button's size.
  • Fixed: the Open-source notices still named version 1.0.1.
  • The Accent colour list now shows the colour in use, and the Controller Studio back button is easier to see.

Version 2.0.0 24 November 2026

  • Controller Studio. Eight looks, four starting layouts, size, opacity and position for every button, named presets, per-game controllers, and a live preview using the same artwork as play. Opens from the pause menu too.
  • Folder scanning. Scan chosen folders and their subfolders, pick what to add, with progress, cancelling, remembered folders and duplicate detection. Your original files are never changed.
  • Offline genres. A built-in catalogue of 4,269 game versions sorts games by genre, with categories you can change.
  • Tiles or list view, tile size, genre filter and your own collections.
  • Original illustrations for games with no cover, local cover matching, and optional online box art that is off until you switch it on.
  • Backups now include controllers, categories, appearance and engine settings.
  • A new opening screen.

Checking your download

The file for version 2.0.1 is called SNESForge.apk. It is 4.9 MB (4,918,646 bytes). Its SHA-256 checksum is:

24ab5b6f80a32871c1385d26b623fdb5ce12602d3ce3814a43de0f272ee28457

On Windows, run certutil -hashfile SNESForge.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
